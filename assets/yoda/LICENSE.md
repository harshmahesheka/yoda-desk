# The Yoda images

The images in this folder (`body.png`, `head_*.png`) and their layout file `yoda.json` are
renders of the 3D model **"Yoda Rig" by TheWorm**:

- Model: https://sketchfab.com/3d-models/yoda-rig-161ecf7f6a6647ae88a8a9dbba6f0cc5
- Author: TheWorm, https://sketchfab.com/Claudiotheworm

added, lit and rendered in Blender), and are shared under the same license:
